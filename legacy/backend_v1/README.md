# Historical v1 backend reference

These files preserve the previous unchecked answer stream, Vertex embedding/Ranking API providers, ingestion entry point and their original tests. They are not a supported runnable package and are excluded from the serving wheel and image. The mounted `/v1` compatibility endpoints now call the verified v2 engine.

The original Git commits preserve the complete runnable snapshot for historical inspection. Do not reintroduce this path as a fallback: valid-looking citation IDs did not establish claim support, and draft text was emitted before validation.
